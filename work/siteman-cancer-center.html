Siteman Cancer Center

Current Project: Full Website Redesign & WordPress Rebuild

Summary

Role: Lead Developer (Current Project)

Live Site: siteman.wustl.edu

Technologies: WordPress, JavaScript, SCSS, Relevanssi, Yoast SEO, ACF, Gutenberg

Current project encompassing a full website redesign and ground-up WordPress rebuild alongside ongoing maintenance of the existing production site. Initial work on the existing site focused on infrastructure and performance — migrating from on-premises to Pantheon hosting, modernizing the deployment pipeline with GitHub Actions and automated code security analysis, implementing advanced caching, and shipping a per-template CSS compilation system — followed by a dedicated set of pediatric cancer templates and components. Development is now centered on the new site launching mid-2026: a fully custom WordPress theme, a dynamic editor-first content architecture, 19 templates and custom post types, 19 custom Gutenberg components, and a purpose-built visitor-guidance tool — all delivered in the first seven months of development.

Project Inheritance & Infrastructure Modernization

Seamless Agency Transition

Inherited Project Management: Successfully inherited and took over maintenance of the Siteman Cancer Center website from a different agency in the spring of 2025, ensuring continuity of service and maintaining critical functionality for cancer patients and their families during the transition period.

Hosting Infrastructure Upgrade

On-Premises to Pantheon Migration: Migrated the site from on-premises hosting (managed by Washington University) to Pantheon hosting, providing numerous benefits:

  • Enhanced Management: Easier site management for both the client and development team
  • Development Environments: Access to Pantheon's DEV/TEST/LIVE environment structure plus multi-dev capabilities
  • Improved Access: Streamlined database and file access for maintenance and development
  • Security Enhancement: Managed Web Application Firewall (WAF) for improved security
  • Performance Optimization: Better caching and performance optimization tools

Legacy Server Retirement

Full Ownership of Hosting & Pipeline: Retired the legacy on-premises servers that had previously hosted the old TEST and LIVE environments. This consolidation gave Modea complete control over the site and deployment pipeline and freed Washington University's IT team from actively managing the infrastructure — while preserving WashU's ownership of the site and ensuring their IT team retains access whenever needed.

CI/CD Pipeline & DevOps Automation

Modernized Deployment Workflow: Designed and implemented a fully automated deployment and code-quality pipeline, replacing the previous manual deployment process:

  • GitHub Actions Deployment: Built a GitHub Action to automatically deploy code changes to the Pantheon DEV environment, streamlining the path from commit to review
  • Automated Code Security Analysis: Integrated SonarQube into the pipeline to run static analysis and security scans on every push to main, surfacing vulnerabilities and code-quality issues before they reach production
  • Daily Automated Backups: Configured daily full-site backups across all three environments (DEV, TEST, LIVE) to ensure reliable disaster recovery and data protection

Performance Optimization & Advanced Caching

Advanced Caching Implementation

Multi-Layer Caching Strategy: Implemented a comprehensive caching architecture to dramatically reduce page load times and server load:

  • Pantheon Advanced Page Cache: Installed and configured Pantheon's Advanced Page Cache for front-end page/HTML/CSS caching, enabling edge-level delivery of cached responses
  • Object Cache Pro with Redis: Installed Object Cache Pro backed by Redis for back-end database query caching, significantly reducing database load and improving response times for dynamic content

Per-Template CSS Compilation System

Rearchitected CSS Delivery: Overhauled how CSS is compiled and served across the site to eliminate wasted bandwidth and render-blocking resources:

  • Previous Approach: All CSS for the entire site was compiled into one massive file and loaded on every page — slow, resource-intensive, and wasteful
  • New Template-Based Compilation: Built a new compilation system that loads CSS on a per-template basis, so each page only pulls in the styles it actually needs

Measured Performance Gains

Real-World Impact: The combined caching and CSS delivery improvements produced substantial, measurable gains on the homepage:

  • Lighthouse Performance Score: Increased from 44 to 78 (Homepage)
  • First Contentful Paint: Reduced from 4.4 seconds to 1.1 seconds

Children's Content Templates: Developed a comprehensive set of specialized templates specifically designed for pediatric cancer content, addressing the unique needs of families dealing with childhood cancer:

Dynamic Content Enhancement

Improved Editor Experience: Significantly enhanced the content editor experience by making previously manual processes dynamic and automated:

Ground-Up WordPress Rebuild (2026 Launch)

Parallel to the ongoing maintenance of the existing production site, a complete rebuild of the Siteman Cancer Center website is underway for a mid-2026 launch. The new platform is being built from scratch — new hosting, new WordPress install, new custom theme, and a new content architecture — with every decision aimed at patient-centered usability on the front end and complete editorial control on the back end. The sections below outline what has been delivered in the first seven months of development.

Platform & Development Environment

  • Pantheon on WUIT's Custom Upstream: The new site was provisioned on Pantheon within Washington University IT's custom upstream, allowing the project to inherit WUIT's automatically-managed plugin updates rather than maintaining them in-house
  • Clean WordPress Install: A fresh WordPress instance was configured from scratch to avoid inheriting technical debt from the legacy site
  • One-Command Local Development: A local development script lets any developer stand up a complete local environment with a single command, dramatically reducing onboarding time and eliminating environment drift
  • Automated Cache-Busting: CSS and JavaScript assets are automatically hashed whenever their source files change, eliminating stale-asset issues in production without manual version bumps

Custom Theme, Built from Scratch

  • Fully Custom Theme: The theme was authored from an empty directory rather than forking a starter or parent theme, ensuring every line of code serves a clear purpose
  • Template-Based CSS Loading: A refined version of the per-template CSS loading system was built into the theme from day one, so each page loads only the styles it actually uses — producing strong performance characteristics out of the gate
  • Gutenberg Editor Styles: Front-end styles are pulled directly into the Gutenberg editor, so content editors can see exactly how a component will render without having to save and navigate to the front end — substantially tightening the editorial feedback loop

Dynamic, Editor-First Content Architecture

The codebase was architected around a hybrid model that combines structured content (custom fields) with Gutenberg blocks in a highly composable system. The result is an architecture that is opinionated enough to keep pages on-brand and flexible enough to let editors assemble novel layouts without developer involvement. A single principle has been carried throughout: every image, string, and piece of content on every page is fully controllable by content editors — nothing is hardcoded.

Find Your Way Tool

The Find Your Way tool gives editors the ability to author guided wizards — multi-step, multiple-choice flows that help visitors navigate vast sets of decision paths on their way to the right care pathway, resource, or next step. The editor interface is a fully custom, Miro-like drag-and-drop canvas embedded inside the WordPress admin, built with vanilla JavaScript and SCSS alone (no framework dependencies). Editors can create nodes, connect them with branching logic, and preview the resulting visitor experience without ever leaving the admin.
